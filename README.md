# **VacancyVault**

## **Описание**
Это проект, который собирает вакансии и работодателей с сайта [hh.ru](https://hh.ru), сохраняет их в базу данных **PostgreSQL**, а затем позволяет удобно анализировать и получать информацию через консольный интерфейс.

---

## 🚀 Цель проекта
Создать систему для:
- получения данных о вакансиях и работодателях через API hh.ru;
- хранения информации в реляционной БД (PostgreSQL);
- выполнения SQL-запросов для анализа данных (средняя зарплата, количество вакансий и т.д.);
- взаимодействия с пользователем через консоль.

---

## **Установка и запуск**
1. Клонируй репозиторий:

```
git clone git@github.com:Smotrichenko/VacancyVault.git
```
2. Установи зависимости через Poetry
```
poetry install
```
3. Запуск проекта
```
poetry run python main.py
```

## ⚙️ Основной функционал

### 📡 Работа с API hh.ru
- Подключение к API и получение данных о **компаниях** и их **вакансиях**.
- Обработка и очистка данных (удаление HTML-тегов, валидация, нормализация).

### 🗄️ Работа с базой данных PostgreSQL
- Автоматическое создание таблиц `employers` и `vacancies`.
- Запись данных о работодателях и их вакансиях.
- Валидация и ограничения (`CHECK`-констрейнты) для корректности данных.

### 🧩 Класс `DBManager`
Класс для взаимодействия с базой данных, предоставляющий методы:
- `get_companies_and_vacancies_count()` — список всех компаний и количества их вакансий.  
- `get_all_vacancies()` — все вакансии с названием компании, зарплатой и ссылкой.  
- `get_avg_salary()` — средняя зарплата по всем вакансиям.  
- `get_vacancies_with_higher_salary()` — вакансии с зарплатой выше средней.  
- `get_vacancies_with_keyword(keyword)` — поиск вакансий по ключевому слову.

### 💬 Пользовательский интерфейс (CLI)
Интерактивное меню, позволяющее:
- выбирать нужный запрос к БД;
- выводить результаты в удобном виде;
- выполнять поиск по ключевым словам;
- просматривать компании, зарплаты, аналитику и др.
