# **VacancyVault**

## 📋 *Описание*
CLI-сервис для сбора, хранения и анализа вакансий с hh.ru.

Сервис получает данные о работодателях и вакансиях через API, сохраняет их в PostgreSQL и предоставляет инструменты для анализа с использованием SQL-запросов.


## 🎯 *Возможности*
- получение вакансий и работодателей через API hh.ru
- сохранение данных в PostgreSQL
- построение SQL-запросов для анализа данных
- получение списка компаний и количества вакансий
- получение списка всех вакансий
- расчёт средней зарплаты
- фильтрация вакансий с зарплатой выше средней
- поиск вакансий по ключевому слову

- pytest

## 💡 *Ключевые особенности*
- хранение данных в реляционной базе (PostgreSQL)
- разделение слоёв: API / загрузка данных / работа с БД

## 💡 *Какую задачу решает проект*
Проект автоматизирует сбор и анализ вакансий:
- агрегирует данные о вакансиях и работодателях
- сохраняет их в структурированном виде в БД
- позволяет выполнять аналитические запросы к данным
- упрощает поиск релевантных вакансий


## 🔔 *Пример использования*
1. Получение данных с hh.ru через API
2. Сохранение работодателей и вакансий в PostgreSQL
3. Выполнение аналитических запросов
   
Примеры запросов:
- список компаний и количество вакансий
- средняя зарплата по вакансиям
- вакансии с зарплатой выше средней
- поиск вакансий по ключевому слову


🗄 Пример SQL-запроса
```
SELECT name, open_vacancies
FROM employers
ORDER BY open_vacancies DESC;
```
📊 Пример результата
```
Компания: Яндекс — 120 вакансий
Компания: Сбер — 98 вакансий
Компания: Тинькофф — 76 вакансий
```

## ⚙️ *Установка и запуск*
1. Клонируй репозиторий:
```
git clone git@github.com:Smotrichenko/VacancyVault.git
cd VacancyVault
```
2. Установи зависимости через Poetry
```
poetry install
```
3. Настройка базы данных
Создать базу PostgreSQL и указать параметры подключения.

4. Запуск проекта
```
poetry run python main.py
```


## 🧪 *Тестирование*
Запуск тестов
```
poetry run pytest
```
